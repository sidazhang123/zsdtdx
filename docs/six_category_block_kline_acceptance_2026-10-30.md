# 六类板块与统一6小时缓存验收

验证日期：2026-10-30。本记录针对当前工作区修改，未发布新版本。

## 接口与身份

板块身份统一为 `(中文分类名称, 板块名称)`。`get_block_names()` 返回二元组列表；`BlockKlineTask.block_name`、行情事件 task 与 rows 中的 `block_name` 使用同一结构；JSON 中为二元素数组，任务输入接受 tuple/list，不再接受裸名称。

| 中文分类名称 | 标记 |
|---|---|
| 概念 | GN |
| 风格 | FG |
| 指数成分 | ZS |
| 通达信基础行业 | HY |
| 研究行业中类 | RS |
| 补充成分 | SP |

目录纳入统计风格、空成分及无代码板块。地区不属于此次指定的六类。相同中文名称在不同分类下独立保留；同分类同名多代码不猜测，按无可确定路由返回空行情。

## 共享完整映射

实现位于 `src/zsdtdx/cache/block_catalog_cache.py`，磁盘文件为配置缓存目录下的 `block_catalog.pkl`，三个板块接口共用。内容包含：六类目录与路由、原始证券成分、股票代码名称表、带分类的股票归属、源文件哈希和日期。有效期与原始三文件统一为6小时，起点为原文下载时间；建图不会重新开始6小时。缓存包含源时间戳和内容哈希，来源变化即失效。

首次构建受进程内锁和跨进程文件锁保护，校验后原子写入；版本、身份、分类、成分及派生映射均校验。损坏、未来时间、超过来源6小时期限、空码表及缺失来源不成为有效缓存。股票名称范围配置不同也不混用缓存。磁盘写失败时同客户端仍在来源有效期内复用内存图。

原始三文件的6小时缓存供股票统计和映射共用。建图优先使用有效缓存，跨午夜不因日期变化强制下载；原始文件到期或损坏先刷新，再重建映射。股票统计等其它客户端提前更新原始缓存后，已运行客户端通过文件元数据识别更新，再核对源时间戳和哈希，使旧内存/磁盘映射失效。热路径不重复解析原文或计算哈希。

补充验证：来源已缓存5小时才建图时，映射仅再有效1小时；映射刚重建但来源到期仍触发下载；来源更新时间戳相同但内容变化仍能更新目录和归属；建图过程中跨到期边界会重新取得有效来源。旧格式版本1、2自动失效，当前格式版本3。

本次完整图含5,580个股票码名、126,662条原始成分关系，以及107,140条股票名称与分类板块的归属关系。验证了新客户端禁止访问源文件和码表时，磁盘重载结果仍与首次构建一致。

## 股票归属契约审查

股票归属保持 `{names, map}`：`map` 的键是股票名称，值为授权变更后的分类二元组；码表缺失代码不进入map。完整缓存和缺文件容错使用同一规范化函数，按原文顺序合并同分类同代码/同名，再在同分类相同股票成分中保留最长名称。跨分类始终独立；未知来源类别一致跳过。完整板块目录保留全部身份，股票归属只返回满足归属规则的子集。

目录记录用于名称与K线路由，单独的规范化 `stock_blocks` 用于股票归属，避免从同名多代码的展示目录反推成分而丢失原始对应关系。缓存校验从stock_blocks重算归属结果。

同次真实快照中，完整缓存输出与共享解析函数逐项一致：778个归属名称、5,580个股票名、107,140条关系。补充8项回归覆盖同代码异名、复合别名冲突、同类相同成分、跨类同名、未知分类、冷磁盘重载、返回修改隔离和空码表不重复获取。另补2项并发/异常清理回归：目录请求不能覆盖部分来源，码表异常仍清理暂存状态。完整回归501项通过。审查发现问题后本轮只修复，暂缓发布和本机升级。
